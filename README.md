## 👋 About Me

Men O‘zbekistonda faoliyat yurituvchi **Full-Stack dasturchi** va
**Backend Engineer**man. Asosan xavfsiz, kengayuvchan va production
muhitiga tayyor web tizimlar hamda REST API’lar yaratish bilan shug‘ullanaman.

Men murakkab biznes talablarini sodda, maintainable va ishonchli dasturiy
yechimlarga aylantirishni yaxshi ko‘raman.

### Asosiy yo‘nalishlarim

- Production darajasidagi backend tizimlar
- REST API va modular arxitektura
- JWT, 2FA va role-based access control
- Tibbiyot, moliya va biznes avtomatlashtirish tizimlari
- PostgreSQL ma’lumotlar bazasi dizayni
- Docker, Linux va deployment
- Web application security va penetration testing
- Test yozish, API hujjatlari va code quality

### Hozirgi faoliyatim

- 🏥 `"RIO vs RIATM"` onkologiya markazida Karmed tibbiy tizimini qo‘llab-quvvatlash
- 🎓 TATU Samarqand filialida axborot texnologiyalari yo‘nalishida ta’lim olish
- 🚀 Scalable backend tizimlar va professional portfolio loyihalarini rivojlantirish

## 🔐 Security Mindset

Men dasturiy ta’minot yaratishda xavfsizlikni keyinchalik qo‘shiladigan
funksiya emas, balki arxitekturaning asosiy qismi deb hisoblayman.

### Xavfsizlikka e’tibor beradigan yo‘nalishlarim

- Secure authentication va authorization

- Secret va environment variable management
- API endpoint’larni himoyalash
