## 👋 About Me

Men O‘zbekistonda faoliyat yurituvchi **Full-Stack dasturchi** va **Backend Engineer**man. Asosan xavfsiz, kengayuvchan va production muhitiga tayyor web tizimlar hamda REST API’lar yaratish bilan shug‘ullanaman.

## 🔐 Security Mindset

Men dasturiy ta’minot yaratishda xavfsizlikni keyinchalik qo‘shiladigan vosita emas, balki loyihaning asos poydevori deb bilaman:

- **Auth & Access:** JWT token lifecycle, 2FA va Role-Based Access Control (RBAC)
- **Data Protection:** Input validation, sanitize qilish, SQL Injection va CSRF/XSS oldini olish
- **Infrastructure:** Rate limiting, brute-force himoyasi va environment maxfiyligini ta’minlash
- **Audit:** Har bir tanqidiy harakatlar uchun log monitoring va audit tizimi

---

## ⚙️ Engineering Principles

- **Security-first:** Xavfsizlik har doim birinchi o‘rinda.
- **Clean Architecture:** Tushunarli, ajratilgan (modular) va texnik qarzlardan xoli kod.
- **Automated Testing:** Testlar yozish orqali kutilmagan regressiyalarning oldini olish.
- **Query Optimization:** Baza so‘rovlarini indekslash va `N+1` muammolarini bartaraf etish.
- **Reproducible Environments:** Docker yordamida har doim barqaror ishlaydigan muhit.
